## Brand & Style

This design system establishes a calm, bright, and light workspace optimized for high-velocity editorial operations, asset management, and structural visibility. The aesthetic combines Scandinavian utility with the energetic pulse of global connectivity, defined by clean canvas surfaces, balanced structural borders, and the signature Holafly Magenta focal points.

### Style Archetype

The system follows a **Minimalist Structural** paradigm with subtle tactile accents:

- **Canvas Restraint:** An uncluttered foundation using near-white surfaces and crisp borders rather than dense drop-shadows or layered skeumorphism.
- **Intentional Chromatic Tension:** The vast majority of the interface remains achromatic (`#FFFFFF`, `#F8F8FB`, `#E4E6EA`), allowing purposeful bursts of Magenta (`#E6485C` and `#E12B57` → `#C8094E`) to direct focus, signify momentum, and denote system actions.
- **Architectural Typography:** Humanist geometry anchored by light numerical figures (weight 300) paired with disciplined regular body weights and deliberate semi-bold structural signifiers.

### Target Audience & Emotional Intent

Built for cross-functional teams, content strategists, and operations directors navigating extensive information architecture. The environment elicits:

- **Clarity & Composure:** Reducing cognitive load during high-density asset evaluation.
- **Modern Reliability:** Communicating speed, precision, and enterprise rigor without appearing sterile.
- **Deliberate Purpose:** Ensuring actionable signals, statuses, and key performance data stand out instantly.

## Colors

The palette balances utility neutrals with vibrant brand markers. Light mode is the default and canonical application theme.

### Primary & Interaction Rules

- **Primary Accent (`#E6485C`):** Reserved for indicator bars, selected navigation markers, active tab underlines, and structural screenshot emphasis.
- **Action Gradient (`#E12B57` → `#C8094E`):** Applied exclusively to primary interactive calls-to-action to surpass 4.5:1 WCAG AA contrast against white text, a threshold the flat brand accent cannot reach alone.
- **Interactive Links (`#D22C49`):** Provides deep, high-contrast readability across text references, table row keys, and breadcrumbs.
- **Focus Indicator (`#2065CE`):** Applied strictly as a 2px outer boundary with 2px offset to guarantee system-wide keyboard accessibility without clashing with the magenta brand markers.

### Status Architecture

Every semantic state utilizes a three-tier system comprising a 10% tint background, a medium-value accent indicator, and a deep, readable foreground label:

- **Success:** `#EDFFF4` background / `#32A45E` icon & line / `#206B43` text.
- **Warning:** `#FFF8EC` background / `#C17B18` icon & line / `#835617` text.
- **Error / Destructive:** `#FFEFEC` background / `#C83D1E` CTA & line / `#841C05` text.
- **Info:** `#EBF3FF` background / `#2065CE` icon & line / `#002968` text.
- **Neutral:** `#F8F8FB` background / `#CCD0D7` icon & line / `#56575A` text.

## Typography

The typographic hierarchy relies on Mulish across all roles, establishing high scannability through weight divergence:

- **Metrics & Figures:** Large KPI values always utilize weight `300` (Light) alongside tabular numerals (`tnum`). This prevents dense numerical values from overpowering structural content while delivering a streamlined modern finish.
- **Narrative & Structure:** Page headings (`h1` through `h3`) utilize weight `400` (Regular). Content clarity is created through scale rather than heavy bold weights.
- **Labels, Headers, and Tags:** Structural table column titles, form labels, and status badges utilize weight `600` (Semi-bold). These elements are rendered strictly in sentence case; all-caps formatting is prohibited to preserve legibility.
- **Line Length Constraints:** Paragraph blocks and descriptive documentation must enforce an optimal reading measure capped at `70ch`.

## Layout & Spacing

The layout is built on a 12-column grid inside a maximum container width of `1200px`, centered within the viewport.

### Layout Rhythm

- **Page Margin:** Outer canvas padding is set to `32px` (`space-3xl`).
- **Section Spacing:** Major content blocks and administrative panels are separated by a vertical rhythm of `40px` (`space-4xl`).
- **Gutter Distance:** Grid columns maintain a steady `24px` (`space-2xl`) gutter.
- **Card Padding:** All standard cards, dashboards, and modal panels feature uniform internal padding of `24px` (`space-2xl`) with `16px` (`space-lg`) gap separation between elements.
- **Tree Hierarchies:** Tree nodes, directory hierarchies, and nested list items indent by `24px` (`space-2xl`) per level.

### Breakpoint Strategy

- **Desktop (>= 1440px):** Persistent left rail navigation fixed at `248px` width. Content canvas fills the remaining width up to a `1200px` max constraint.
- **Tablet (1024px - 1439px):** Navigation rail collapses into an icon-only strip fixed at `72px` width. Page margins reduce to `24px`.
- **Mobile (< 1024px):** Navigation rail converts to a hidden overlay modal triggered by the top bar. Main content switches to single-column stacking with `16px` page margins.

## Elevation & Depth

This design system avoids multi-layer shadow stacks in favor of flat structural clarity:

### Layer Hierarchy

1. **Base Canvas:** The foundation layer rendered in Neutral 200 (`#F8F8FB`).
2. **Surfaces & Cards:** Content panels sit flush at `#FFFFFF` without shadows, delineated purely by a 1px solid border in Neutral 300 (`#E4E6EA`).
3. **Floating Overlays (Level 1):** Suggestion panels, search dropdowns, tooltips, and toast notices employ `--shadow-float`:
   - Value: `0 8px 24px rgba(41, 43, 46, 0.12)`
   - Surfaces retain their 1px `#E4E6EA` outline to ensure visual boundary contrast against white parent containers.
4. **Modal Dialogs (Level 2):** Critical interruption dialogues employ `--shadow-modal`:
   - Value: `0 16px 40px rgba(41, 43, 46, 0.20)`
   - Modals are paired with a backdrop scrim: `#292B2E` tinted to 40% opacity (`rgba(41, 43, 46, 0.40)`).

## Shapes

The interface utilizes a disciplined radius scale to clearly differentiate interactive controls from container architecture:

- **Cards, Panels, and Drawers (`rounded-lg` / 16px):** All major content structures, search popover windows, and dashboard cards maintain a `16px` radius.
- **Buttons, Inputs, & Form Selects (12px):** Standard interactive elements use a `12px` radius, providing a tactile, distinct feel that differentiates them from their enclosing `16px` cards.
- **Tooltips (8px):** Informational popovers and contextual helpers utilize an `8px` radius.
- **Field Highlights (4px):** Strict 4px corners reserved for image screenshot focal markers and target bounding boxes.
- **Status Badges & Chips (`rounded-full` / 2000px):** All entity tags, filtering chips, and status badges are rendered as full pills.

- **Primary Button:**

  - Border: None
  - Radius: `12px`
  - Height: `44px` (standard), `36px` (compact)
  - Hover: Opacity brightness shifts down 8%
- **Secondary Button:**
  - Background: `#FFFFFF`
  - Text: `#292B2E`, weight 600, 14px
  - Border: 1px solid `#CCD0D7`
  - Radius: `12px`
  - Hover: Border color transitions to `#56575A`
- **Tertiary / Ghost Button:**
  - Background: Transparent
  - Text: `#D22C49`, weight 600, 14px
  - Hover: Background fills with `#FFEEF0`

### Chips & Badges

- **Status Chips:**
  - Height: `24px`
  - Radius: `2000px` (pill)
  - Padding: `0 10px`
  - Typography: 12px, weight 600
  - Content: Must include a 16px crisp outlined vector icon paired with the status label.
  - Palettes correspond strictly to semantic tokens (e.g., Success: `#EDFFF4` bg, `#206B43` text, `#32A45E` icon).

### Tables & Data Lists

- **Header Row:**
  - Height: `40px`
  - Background: `#F8F8FB`
  - Border Bottom: 1px solid `#E4E6EA`
  - Typography: 12px, weight 600, sentence case, color `#56575A`
- **Data Rows:**
  - Height: `48px`
  - Background: `#FFFFFF`
  - Border Bottom: 1px solid `#E4E6EA`
  - Typography: 14px, weight 400, color `#292B2E`
  - Row Hover: Background changes to `#F8F8FB`
  - Key Links: Stylized in `#D22C49`, weight 600

### Checkboxes & Radios

- **Size:** `20px` x `20px` target box on a minimum `44px` touch footprint.
- **Unchecked:** 1.5px border `#CCD0D7`, background `#FFFFFF`.
- **Checked:** Background `#E6485C`, border `#E6485C`, check vector `#FFFFFF` with 2px stroke.
- **Radius:** `4px` for checkboxes, `50%` for radio dials.

### Iconography

- Rendered via crisp outlined geometry with a uniform 1.5px stroke and rounded stroke-caps.
- Base size is `20px` for navigational controls and actions; `16px` for dense table actions and status chips.
- Icons inherit text color (`currentColor`) except when serving as semantic chip indicators.
